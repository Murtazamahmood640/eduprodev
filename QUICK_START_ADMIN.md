# EduPro Admin Portal - Quick Start

## 🚀 Fast Access

### Step 1: Go to Login Page
```
http://localhost:3000/auth/login
```

### Step 2: Select Admin Role
- Click the **Shield Icon** button (third option)
- You'll see it highlighted with a gradient background

### Step 3: Login
- **Email:** admin@edupro.academy (or any email)
- **Password:** admin123 (or any password)
- Click **"Enter Admin Portal"**

### Step 4: Access Dashboard
- You're now in the admin portal at `/admin/dashboard`
- Sidebar shows all admin sections

## 🎯 Common Tasks

### Add a Student
1. Go to Students → Click **"Add Student"**
2. Fill: Name, Email, Phone, Courses
3. Click **"Add Student"**

### Add a Teacher
1. Go to Teachers → Click **"Add Teacher"**
2. Fill: Name, Email, Subject, Qualification
3. Click **"Save Teacher"**

### Add a Course
1. Go to Courses → Click **"Create Course"**
2. Fill: Title, Instructor, Level, Price
3. Click **"Create Course"**

### Record a Grade
1. Go to Results → Click **"Add Result"**
2. Select: Student, Course, Enter Score
3. Grade auto-calculates → Click **"Add Result"**

### Issue Certificate
1. Go to Certificates → Click **"Issue Certificate"**
2. Select: Student, Course
3. ID auto-generates → Click **"Issue"**

## 🎨 Color Coding

- 🔵 **Blue** = Primary actions, main metrics
- 🟢 **Green** = Success, completed items
- 🟡 **Amber** = Pending, warnings
- 🟣 **Purple** = Secondary items

## ❌ Troubleshooting

**Can't see Admin button?**
→ Refresh page or clear browser cache

**Forms won't submit?**
→ Make sure all fields are filled

**Data not saving?**
→ Check internet connection, refresh page
